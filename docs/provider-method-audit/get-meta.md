## Matches

- **Registration & CLI validation (`## get-meta` § Registration, § Inputs):** Registered at `cmd/gc-runtime-rex/main.go:116` as `get-meta <name> <key>` (`required: 2`) and in `keyedOps` (`main.go:97`). Missing/empty `<name>` or `<key>` fails before dispatch with exit `1`, empty `stdout`, and a `stderr` diagnostic (`main.go:154-161`, `cmd/gc-runtime-rex/dispatch_test.go:129-152`). Extra positional arguments are ignored (`main.go:359`).
- **Stdin ignored (`## get-meta` § Registration):** `opGetMeta` (`main.go:358-365`) ignores `stdin` and never reads from it.
- **Success output & byte preservation (`## get-meta` § Success output, § Unverified):** `opGetMeta` (`main.go:358-365`) writes the raw value via `io.WriteString(out, value)` with no trailing newline added and no JSON framing, exiting `0` (`main.go:179`). Arbitrary bytes including spaces, newlines, and invalid UTF-8 round-trip identically (`internal/provider/stores_test.go:111-118,139-149`, `internal/provider/meta_test.go:14-24`, `cmd/gc-runtime-rex/dispatch_test.go:245-256`).
- **Unset key & unknown session (`## get-meta` § Success output):** Missing files and unset keys return `"", nil` (`internal/provider/meta.go:56-64`, `internal/provider/filestore.go:55-67`, `internal/provider/stores.go:296-303`), producing empty `stdout` and exit `0` (`meta_test.go:26-32`, `stores_test.go:176-181`, `dispatch_test.go:254-256,476-481`).
- **Corrupt or unreadable store (`## get-meta` § Failure cases):** Corrupt JSON, invalid `value_b64`, or unreadable store paths return an error (`filestore.go:55-67`, `stores.go:296-303`, `stores_test.go:151-174,183-194`) and exit `1` with empty `stdout` and `gc-runtime-rex: get-meta: ...` on `stderr` (`main.go:171-174`, `dispatch_test.go:463-474`).
- **Incarnation lifetime (`## get-meta` § Conflicts):** `Stop` calls `clearIncarnations` -> `p.metaClear` -> `fileMetaStore.Clear` (`internal/provider/provider.go:535,542,549-565`, `stores.go:324-328`), removing all metadata for the session so keys do not outlive `stop`.
- **Stdout write failure (`## Shared RPP contract` § Failure envelope):** If writing buffered output to `stdout` fails, `runWithContext` logs to `stderr` and returns exit `1` (`main.go:175-178`).

## Unverified

- Whether any gc release newer than `v1.5.1` sets `GC_EXEC_DEADLINE_MS`, relies on `get-meta` failing when the runtime core is unreachable or the session is foreign, or expects values over 64 KiB to be rejected.
- Whether gc ever calls `GetMeta` with an empty key (noted as unverified in `## get-meta` § Unverified).
