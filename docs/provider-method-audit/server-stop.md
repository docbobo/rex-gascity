## Matches

- **Unknown-op envelope (`## Shared RPP contract` §Failure envelope):** `runWithContext` (`cmd/gc-runtime-rex/main.go:135-143`) returns exit `2` (`exitUnknown`, `cmd/gc-runtime-rex/main.go:32`) with empty stdout, a prefixed stderr message (`gc-runtime-rex: unknown operation "server-stop"`), and without reading `stdin` (`stdin` is only passed to `spec.handle` at `cmd/gc-runtime-rex/main.go:161`). `TestUnknownAndUnimplementedOps` (`cmd/gc-runtime-rex/dispatch_test.go:108-120`) verifies this path for unknown and unimplemented ops.
- **Handshake capability parity with gc v1.5.1 (`## server-stop` §Registration, §Conflicts):** `handshake` (`cmd/gc-runtime-rex/main.go:36`, tested by `TestProtocolHandshake` at `cmd/gc-runtime-rex/dispatch_test.go:83-106`) declares only `["report-attachment","report-activity"]` and omits `server-lifecycle`, matching gc v1.5.1's capability table and the parity record (`docs/provider-herdr-parity.md` §server-stop).
- **Signal cancellation wiring (`## Shared RPP contract` §Deadlines and cancellation):** `main` (`cmd/gc-runtime-rex/main.go:46`) wires `SIGTERM`/`SIGINT` to `signal.NotifyContext`, though `server-stop` exits `2` before any cancellable work.

## Unverified

- Whether any gc release after `v1.5.1` sends `server-stop` or recognizes `server-lifecycle` (`## server-stop` §Unverified).
- Whether `GC_EXEC_DEADLINE_MS` or `GC_RPP_FAULT` is passed by any external caller in practice (neither is read in `cmd/gc-runtime-rex/main.go` or `internal/provider/*.go`).
- Pack-internal `herdr-core` / `hc` details (`hc server.stop` semantics, exact end state when the 30 s deadline expires mid-op without cancel, and whether anything wraps gc's `exec` provider with `ServerLifecycleProvider` at `v1.5.1`) are outside the Go provider codebase (`## server-stop` §Unverified).
