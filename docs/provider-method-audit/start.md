## Matches

- **Registration & args**: `start` registered with 1 required non-empty `<name>` arg (`cmd/gc-runtime-rex/main.go:120,177-183`); extra args ignored (`main.go:320-338`).
- **Success envelope**: The op's output is buffered and flushed only on success; `start` writes none, so it exits 0 with empty stdout (`cmd/gc-runtime-rex/main.go:184-204`, `## start` > Success output).
- **Empty stdin**: Empty or whitespace-only stdin fails with `parse start config: empty stdin`, exit 1, empty stdout and no pane launched (`cmd/gc-runtime-rex/main.go:265`, `TestStartEmptyStdinFails`; `## start` > Failure cases).
- **Collision & recycle**: `StartNew` (`internal/provider/provider.go:347-382`) serializes under `withNameLock`, checks `IsRunning`, returns `ErrAlreadyRunning` -> `"session %q already running"` (`cmd/gc-runtime-rex/main.go:290-293`, matches gc's collision detector), and recycles dead panes (`provider.go:426-608`). With `fresh_only`, a held binding (primary or alias) or a live pane is refused with `ErrFreshCollision`, mapped to exit 73 `session %q already exists (fresh_only)` (`provider.go:350-368`, `main.go:287-289,218-220`; `TestStartNewFreshOnlyRefusesAHeldName`, `TestStartFreshOnlyExits73`).
- **Agent `env` unset semantics**: `launch.Command` (`internal/launch/launch.go:115-128`) emits `env -u K` for `""` values when `command` is non-empty.
- **`pre_start` env unset semantics**: an empty `env` value removes the key from the hook environment instead of setting `K=` (`launch.mergeEnv`, `internal/launch/launch.go:233-252`, via `Plan.MergedEnv` at `internal/provider/provider.go:514-517`; `TestMergeEnvEmptyValueUnsets`, `TestPreStartEnvEmptyValueIsUnset`), and a non-empty value is passed through unchanged (`TestMergeEnvNonEmptyValuePassedThrough`, `TestPreStartEnv`). Matches gc's "empty = unset" env contract (`docs/reference/exec-session-provider.md:269` at v1.5.1) and herdr-core's setup-hook env (`herdrcore/envplan.py:67-71`, `herdrcore/lifecycle.py:599-609`). A bare shell still starts without `env` (an intentional limitation; parity row 9).
- **Directory & overlay safety**: Checks `work_dir` is an existing directory (`internal/provider/provider.go:534-538`) and refuses symlinks/non-regular files during `overlay_dir`, `pack_overlay_dirs` and `copy_files` staging (`internal/provider/overlay.go:28-348`); staging writes through an `os.Root` so nothing lands outside `work_dir` (`overlay.go:115-220`; `TestStartStagingRefusesDestinationSymlink`). A `copy_files` destination that leaves `work_dir` is refused with a warning, not a failed start (`overlay.go:139-143`; `TestStartCopyFilesRefusesEscapingDestination`), a source already at its destination is skipped (`overlay.go:146-152`; `TestStartCopyFilesSkipsASourceAlreadyAtItsDestination`), and a non-directory `overlay_dir` source fails the start (`overlay.go:76-78`; `TestStartOverlayDirNotADirectoryFails`).
- **Seeded identity & rollback**: Seeds `startIdentityMetaKeys` and provisional binding before blocking launch (`provider.go:556-561`) and clears them on error/SIGTERM rollback (`provider.go:443-446`, `main.go:45`).
- **Start config fields**: `session_setup`/`session_setup_script` run after launch and before the nudge as warnings only, with the launched pane's own projected env (`internal/provider/provider.go:1028-1060`, `provider.go:325-339,371-381`), `session_live` emits one `SESSION_LIVE_SKIPPED` warning, `overlay_dir`/`copy_files` stage before `pre_start` (`provider.go:496-505`; `TestStartStagesBeforePreStart`), and `fresh_only` gives exit 73 (`provider.go:352-359`, `main.go:287-289`; `TestStartStagesOverlayDirAndCopyFiles`, `TestStartCopyFilesOmittedRelDstStagesIntoWorkDir`, `TestStartSessionSetupRunsAsWarningsOnly`, `TestStartSessionSetupOnlyAfterALaunch`, `TestStartSessionSetupSeesProjectedLaunchEnv`, `TestStartWarnsSessionLiveSkipped`).
- **First-turn nudge**: `deliverStartupNudge` (`internal/provider/nudge_delivery.go:106-192`) waits for `program_status` idle (or, when `ready_prompt_prefix` is set, the pane's prompt — `ready_delay_ms` is a capped floor only when no prompt is set), reads the pane's screen and withholds the nudge when it shows a startup dialog gc knows (`readiness.go:78-228`, matching herdr-core's `withholds_first_turn`/`shows_dialog` at `herdrcore/readiness.py:36-93`), retries with `ctrl+u` clear, and marks `GC_STARTUP_DELIVERY_UNCONFIRMED` in meta when unconfirmed or withheld (`TestStartReadinessUsesReadyDelayMs`, `TestStartReadinessUsesReadyPromptPrefix`, `TestScreenHasPromptPrefixMatchesGcPaneShowsReadyPrompt`, `TestShowsDialogMatchesHerdrCoreReadiness`, `TestWithholdsFirstTurnMatchesHerdrCoreReadiness`, `TestStartupNudgeWithheldOnStartupDialog`, `TestStartupNudgeDeliveredWhenDialogGone`).
- **Post-launch liveness**: `Start`/`StartNew` call `failIfAgentEnded` (`internal/provider/provider.go:391-409`) after the launch, and `waitForStartupReady` (`nudge_delivery.go:377-409`) stops a readiness wait when the pane's program ends; the first case fails `"<name>: the agent exited during startup"`, the second `"<name>: the agent exited during startup, before its first turn"` (exit 1, `TestStartInstantExitFails`, `TestStartMissedFirstTurnFails`). `lifecycle=one_shot` skips both (`TestStartOneShotInstantExitSucceeds`, `TestStartOneShotMissedFirstTurnSucceeds`), matching herdr-core's `_fail_if_ended`/`first_turn` (`herdrcore/lifecycle.py:1027-1036,1113-1125`). The dead pane is left in place for gc's post-failure stop.

## Unverified

- Real `rex` CLI behavior on `NewWindow`/`NewSplit` cancellation near gc's 2 s SIGTERM-to-SIGKILL grace window (`cmd/gc-runtime-rex/main.go:41-46`).
- Whether a real instant Rex exit is visible to the single immediate post-launch liveness probe (`failIfAgentEnded`), rather than only to a wait (the pack's 5 s/30 s `_await_agent`); the dispatcher tests prove the failure against the fake's `ProcessFunc`, not against a real Rex process read.
- Cleanup of detached grandchild processes spawned by `pre_start` hooks on cancellation (`internal/provider/provider.go:614-644`).
