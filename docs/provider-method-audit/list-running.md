## Matches

- **Registration & stdin (`## list-running` § Registration):** Registered in `ops` as `"list-running": {0, "list-running [prefix]", opListRunning}` (`cmd/gc-runtime-rex/main.go:112`); `opListRunning` (`main.go:315-328`) ignores `stdin`.
- **Inputs & prefix matching (`## list-running` § Inputs):** Accepts 0 or 1 positional arg (`prefix := ""` when omitted, `main.go:316-319`), ignores extra args beyond `args[0]`, and matches with case-sensitive `strings.HasPrefix` (`provider.go:654,667,676-689`; `dispatch_test.go:230-241`; `phase4_test.go:48-63`).
- **Output format & ordering (`## list-running` § Success output):** Emits sorted (`sort.Strings`, `slices.Compact` deduplication at `provider.go:672-673`) one-name-per-line output with trailing `\n` (`fmt.Fprintln`, `main.go:324-326`), and empty `stdout` with exit `0` when nothing matches (`main.go:175-179`).
- **Buffered failure & error propagation (`## list-running` § Failure cases, `## Shared RPP contract` § Failure envelope):** `opListRunning` buffers into `out` and writes nothing to `stdout` on error (`main.go:169-175`); state-dir errors, non-unreachable `BlockProcess` errors, and `SIGTERM`/`SIGINT` cancellation exit `1` with prefixed `stderr` (`main.go:46,161-174`). Never returns exit `2` for a valid `list-running` invocation.

## Unverified

- Exact behavior against a *live* Rex daemon when Rex is unreachable or returns an unexpected error from `rex api call block.method` (`process`) – tests use `faketest.Fake` (`dispatch_test.go:230-241`, `phase4_test.go:48-63`). The unreachable path itself is pinned: `rex` exits 4 with `no Rex server is running at <socket>` when the socket is absent, and `TestListRunningUnreachableRexIsEmpty`, `TestListRunningUnreachableRexIsEmptyExitZero`, and `TestServerUnreachableMapsToErrUnavailable` cover the mapping.
- Behavior when `ListRunning` output exceeds 8 MiB (no test exercises >8 MiB output).
- Whether any gc v1.5.1 caller passes extra positional arguments beyond `<prefix>` to `list-running`.
